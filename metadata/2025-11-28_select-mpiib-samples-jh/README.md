Selection Process
 - Take 180 random samples from NW (North-Western) and W (Western) provinces
   - This is a 'representative' set; allele freqencies have not be skewed by selection
 - From the remaining samples in NW/W, 80 were clonal
 - Randomly sample 60 of these
   - This *enriches* for clonal samples, which are easier for iHS/EHH analyses
   - But by sampling only clonal, we may have some bias in this set
 = 180 representative + 60 clonal = 240 total from NW/W
 - Sample 60 from Eastern and Muchinga provinces (in fact 59 available)
   - These are a set I could use for comparison
